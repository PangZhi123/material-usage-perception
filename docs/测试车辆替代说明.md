# 测试车辆替代说明

当前联调阶段缺少混凝土罐车视频，允许将 `test-data/test-video.mp4` 中的红色自卸货车作为混凝土罐车的替代目标，测试车辆跟踪、实时报文、区域状态、作业事件与估算量展示。

本地 `models/best.pt` 在该视频首帧已将红色货车识别为 `transporter`，置信度约 0.90。现有检测适配器默认选择此类别，因此无需修改模型类别、放宽到所有施工设备，或生成固定检测框。接口仍返回 `className: transporter`。

替代测试中的作业事件和混凝土估算量仅用于验证软件流程，不能作为真实卸料或混凝土消耗的验证数据。车辆需满足配置的区域和停留等条件，才会产生相应作业事件。

部署前使用真实罐车视频验证模型分类、检测与跟踪效果；必要时更换或训练权重，并通过 `MATERIAL_PERCEPTION_MODEL_PATH` 和 `MATERIAL_PERCEPTION_MODEL_VERSION` 配置部署模型。当前无需切换类别开关。

若实时页面仍持续返回 `objects: []`，应核对服务实际加载的模型、输入视频及其时刻和跟踪输出。本地首帧检测成功不代表远端服务或整段视频已经验证通过。
