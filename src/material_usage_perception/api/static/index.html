历史视频分析

可测试 · 真实模型推理

1. 上传或注册视频

视频已在服务器：免上传登记

允许目录由 MATERIAL_PERCEPTION_LOCAL_VIDEO_ROOT 设置，默认 data/videos；不能填写服务器绝对路径。

上传成功后会显示真实视频 ID。

2. 准备场景

选择本地 MP4 可预览和截帧。服务端登记的视频如需截帧，请再选择本地同一文件。视频播放进度与后端分析进度独立。

3. 启动分析任务

保存完整轨迹。请选择录像适用的配置版本；本版同时仅允许一个历史任务，停止完成后才可重试，不占用实时相机。
